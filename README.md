# Pager

> Verify reality. Pay instantly.

Pager is a decentralized real-world verification platform built on Monad.

Users can post location-based bounties with crypto rewards, and nearby locals can submit proof through images and reports to earn rewards instantly.

---

## Problem

The internet spreads rumors faster than truth.

People cannot easily verify:
- Breaking events
- Local situations
- Disasters
- Concerts
- Business activity
- Ground reality in another city or country

There is no decentralized incentive system for verifying real-world truth.

---

## Solution

Pager creates a decentralized bounty network for real-world verification.

### Example

A user posts:

> “Is there really a concert happening at this location?”

Reward:
- 5 USDC

A nearby local:
- Visits the location
- Uploads proof
- Shares images/videos
- Submits verification

The creator approves the submission and the reward is released instantly on Monad.

---

## Features

- Location-based bounties
- Image proof submissions
